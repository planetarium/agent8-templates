# Status — basic-3d-r3f-skeleton

## Implemented

- Freeview (orbit) / sideview (side-follow) camera from one `VIEW_MODE` line
- Player run + jump with coyote time, input buffer, consume-on-jump (tested)
- Keyboard + mouse (drag orbit, wheel zoom) and touch joystick + JUMP
- Sky, fog, hemisphere light, shadowed sun, box level
- Lazy rapier demo (`?physics=1` or `PHYSICS_DEMO = true`)

## Not yet

- Character model / animation, sound, HUD, game rules
- Multiplayer (`@agent8/gameserver` unwired)
