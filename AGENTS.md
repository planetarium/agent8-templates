# AGENTS.md

Guidance for coding agents working in this repository.

## Browser Support

**Browser Support:** Baseline Widely available. Newer features only with feature detection and graceful degradation (mobile browsers, in-app WebViews, desktop browsers).

Games built from these templates run on any device: mobile browsers, in-app WebViews, and desktop browsers. iOS WebViews are tied to the device's iOS version, so older engines stay in use long after a feature ships elsewhere.
